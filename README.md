# NOCTRA

Лендинг независимой технологической студии NOCTRA. Статический сайт: один `index.html` и три видеоролика в `media/`.

## Структура

- `index.html` — вся страница (HTML, CSS и JS внутри)
- `media/` — видеовставки (`stream.mp4`, `lab.mp4`, `monitor.mp4`)
- `deploy/` — конфиг nginx и скрипт первичной настройки сервера
- `.github/workflows/deploy.yml` — автодеплой на сервер при пуше в `main`

## Локальный запуск

```bash
python3 -m http.server 8000
```

Открыть http://localhost:8000. Видео не загрузятся при открытии файла двойным кликом, нужен HTTP-сервер.

## Видео

Ролики 1280×548, 24 к/с, 10 секунд, зациклены. Если заменить файл в `media/`, он подхватится сам; без файла страница показывает canvas-анимацию.

## Деплой

Один раз на сервере: `bash deploy/setup-server.sh` (ставит nginx и подключает конфиг).

Дальше каждый пуш в `main` запускает GitHub Actions, который копирует `index.html` и `media/` в `/var/www/zerion` по SSH. Нужны секреты репозитория: `DEPLOY_HOST`, `DEPLOY_USER`, `DEPLOY_SSH_KEY`.

## Заглушки

Контакты `hello@noctra.dev` и `@noctra_dev` в разделе «Контакт» нужно заменить на реальные. Форма обращения пока ничего не отправляет.
